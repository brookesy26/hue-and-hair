# WCAG 2.2 applicability and evidence register

Reviewed against the [official W3C WCAG 2.2 Recommendation](https://www.w3.org/TR/WCAG22/) on 8 October 2026. All **86 current criteria** are listed by their normative number and level. Consult the linked standard for the authoritative requirement text. Criterion 4.1.1 was removed from WCAG 2.2 and is therefore recorded separately below, rather than counted as a current requirement.

This is an implementation review checklist, **not a conformance declaration**. No manual screen-reader, keyboard, zoom or criterion-level visual result is claimed by this initial register. Passing TypeScript, unit tests or axe does not satisfy this evidence requirement.

- **Pending manual review**: the feature is applicable or requires a contextual decision. The observation describes implementation intent, not proof.
- **Not applicable — feature absent**: source inspection found no triggering feature in this release. Confirm on the final deployment and revisit if scope changes.
- For each completed review, record date, commit/deployment, browser and assistive-technology versions, exact page/state, result, evidence and remediation. Replace a pending status only when that evidence exists.

The source observations refer to shared layout/CSS, SiteHeader, Media, Gallery, Assessment and validated catalogue copy. Planned imagery must still be inspected once the actual final assets exist.

## Removed criterion and conformance boundary

4.1.1 is obsolete and removed from WCAG 2.2. Continue sensible HTML validation and inspect malformed markup where it affects other criteria; do not misreport this removed criterion as a WCAG 2.2 failure or pass.

A future conformance statement must consider full pages and complete processes, supported technology combinations and non-interference, in addition to individual criteria. The assessment process includes choosing answers, going back, reviewing results, restarting and the uncertain outcome. Mobile navigation and filter states are part of the same page evaluation.

Known manual-review priorities: actual generated-image alternatives and crops; AAA text contrast; non-text and focus contrast; focus restoration in every browser; full focus visibility; 44px targets and exceptions; location cues; specialised vocabulary and abbreviations; reading level; the complete visual-presentation requirement and any user-adjustment mechanism. These are pending review items, not confirmed failures or passes.
