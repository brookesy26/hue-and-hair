# Root image review

The blunt-bob front/three-quarter view pair established the cream seamless background, soft daylight and understated clothing. Four editorial assets and eight comparison illustrations were generated individually. Fourteen other hairstyle front views were generated as individual portraits and visually inspected before reference-based side edits. The UI contributor produced the remaining15pairs; see image-review-ui.md.

All72 selected images were inspected directly at generation, then reviewed in the exported layouts. Front/side identity, hair colour, texture, visible ends and plausible anatomy were checked. The blunt bob secondary view is three-quarter rather than a strict90-degree profile; it still shows the outline. Other secondary views are side profiles. Gallery previews use containment to preserve hair; detail views use natural aspect ratios. No image asserts a real client result or colour-season diagnosis.

Comparison subjects stay consistent inside each two-view illustration. Captions and alt text describe actual coral/rose, peach/pink, blue, sage/emerald, light/deep blue, lavender/plum, ivory/white and terracotta/burgundy fabrics. Screens, generated lighting and synthetic anatomy remain illustrative limitations.

Selected original bytes are retained with hashes in image-manifest.json; unselected cropped braid output remains outside the repository at the generation tool's original location. There are72 published WebP files. The portrait sets represent diverse adults across ages and four texture categories without assigning colour seasons by gender or ethnicity.
