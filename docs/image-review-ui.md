## Prompt method

Front prompts use the corresponding src/content/image-prompts.json text with initial `Two-view` changed to `Single-view` and the two-panel/identical-both-views instructions replaced by: `Single front-facing portrait, head and upper torso. One person, one view.`

Sides use the selected front portrait as edit target and request only a camera change to exact 90-degree profile, preserving identity, age, skin tone, hair colour, texture, cut, length, parting, charcoal clothing, cream background and diffuse lighting. Every side prompt requires one person, one portrait, no panels, text or watermark, and complete hair silhouette including all ends. Braids use upper-thigh framing to retain all tips.
